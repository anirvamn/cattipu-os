# Documentation map

CATTIPU has a lot of documents because every sprint left a report. **You
only need the ones for what you're doing.** Everything under "History" is
safe to ignore.

## Start here (everyone)

| Read | For |
|---|---|
| [`../README.md`](../README.md) | What CATTIPU is, the agenda, how to run it |
| [`../CONTRIBUTING.md`](../CONTRIBUTING.md) | Setup, workflow and the five rules a pull request must follow |
| [`ROADMAP.md`](ROADMAP.md) | Where the project is going, phase by phase |

## When your change needs it

| If you're… | Read |
|---|---|
| Changing anything visible (colours, type, spacing, windows) | [`DESIGN_CONSTITUTION.md`](DESIGN_CONSTITUTION.md); [`TYPOGRAPHY.md`](TYPOGRAPHY.md) for font roles |
| Adding or changing an icon | [`../design-system/ICON_REGISTRY_v1.0.md`](../design-system/ICON_REGISTRY_v1.0.md) |
| Looking for where something lives in the code | [`HANDOFF.md`](HANDOFF.md) §5, then [`COMPONENT_LIBRARY.md`](COMPONENT_LIBRARY.md) |
| Touching project state, progress or status | [`ARCHITECTURE.md`](ARCHITECTURE.md) (state is derived, never stored) |
| Working on Memory, AI files, Forge or Launch | The matching sprint report: [`MVP-05`](MVP-05_REPORT.md) (Memory), [`MVP-06`](MVP-06_REPORT.md) (AI files), [`MVP-07`](MVP-07_REPORT.md) (Forge), [`MVP-08`](MVP-08_REPORT.md) (Launch) |
| Picking up a whole roadmap sprint | [`HANDOFF.md`](HANDOFF.md) §7, and comment on the issue first |
| Wondering *why* a past decision was made | [`DECISIONS.md`](DECISIONS.md) |
